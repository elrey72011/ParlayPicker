## Why M0 keeps stalling

1. **Any change to a test file is rejected by the protected-scope guard**
   (`scripts/check_launch_change_scope.py` -> `NCAAF_FILTERED_SCOPE_REJECTED`)
   unless a new successor seal is written. The previous one-line timeout change
   needed about 2,500 lines across 13 files (commit `a8c9057`) plus a 2,100-line
   seal (`f635329`). It also needed regenerated profile and context JSON files
   that come from tooling outside this repository.
2. **The guard tests dominate CI time.** Of the ~9.8 h estimated suite cost in
   `scripts/ci_test_file_costs_v1.json`, about 8.1 h (~83%, filename-based
   estimate) belongs to scope, seal, capacity, provenance and historical-reconstruction
   tests. Each new seal adds more of them, so capacity worsens with every fix.
3. **Capacity is modeled from Windows timings.** These run roughly twice as slow
   as hosted Ubuntu, and the model keeps the slowest observation for each file, so
   projections can only get worse.
