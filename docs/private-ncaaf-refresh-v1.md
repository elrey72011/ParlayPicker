# Private NCAAF prediction through Refresh

The normal **Refresh picks** button can use one explicitly selected, reviewed
private spread comparison. This route reuses the native spread caller,
one-use inference journal, custody, private capture, export and static replay.
It never fetches histories or quotes, fits a model, registers acceptance, funds
a wager or publishes a result.

The selection file contains `version`, the reviewed pair `packet` and the
separately authorized `authorization`. Uploading it creates no authority: the
existing exact `AUTHORIZED_INFERENCES` configuration, original custody receipts
and secure custody root must already agree. Missing evidence returns UNAVAILABLE
without a live-provider fallback.

The explicitly versioned conditional contract requires reviewed mathematical
assumptions: signed full-game spread, overtime included, and integer ties return
the stake. Unverified product, listing and governing edition stay null. The
result is labelled conditional private research, not verified offer admission.
The earlier strict owner, wagering and commercial routes keep their requirements.

Both sides retain unconditional cover, push and loss. Ranking uses unconditional
model cover probability, with a tie when equal. Conditional-on-no-push probability
is separately labelled and unknown at a zero denominator. Estimated EV per unit
is `cover * decimal_price + push - 1`; price and EV do not determine this ranking.
Higher cover probability does not establish greater EV or profitability.

The compatible ridge model estimates final home-minus-away margin with its
unchanged discrete residual distribution. Its calibration remains unvalidated.
Synthetic histories demonstrate integration; authentic historical inputs establish
replay only. Neither establishes a current prospective prediction. Original input
age, strict seven-day history cutoff, provider-observation freshness, pregame
rejection, substantive reviews and separate inference authorization remain required.

The source graph and exact predecessor images are bound in
`docs/paid-launch/ncaaf-private-refresh-bindings-v1.json`. Physical source checks
run before importing application dependencies and again at private selection load.
The CI stability successor seals this separately reviewable feature scope together
with the release repair; passing checks is not predictive validation.
