# Six-sport provider capability audit

This is an audit of the implemented provider contracts on 2026-09-23. It is not evidence that a credentialed call succeeded in this workspace. The current local environment has no Drive, Odds API, or CFBD credentials. A provider capability remains operationally unverified until a real scheduled run restores and replays its response.

| Sport | Schedule/events and identity | Side and total with prices | Results and timestamps | Remaining boundary |
|---|---|---|---|---|
| NFL | The Odds API `events` returns event ID, team names and scheduled start; the current NFL adapter checks exact event/name identity but does not capture stable participant IDs. | `spreads` and `totals` quotes with bookmaker, point, American price and market update time. | `scores` supplies final score and update time; collector records receipt and availability. | Stable team IDs are a canonical blocker. No certified last pregame close; score comparison is not a verified bookmaker settlement. |
| NCAAF | CFBD games supply game/team IDs, start and score; Odds API supplies a separate event identity. The adapter blocks ambiguous joins. | Odds API `spreads` and `totals` snapshots include price and update time. | CFBD game result is captured with local availability; later recovery cannot move that time earlier. | Cross-provider identity must be verified per event; no certified close or bookmaker settlement. |
| NBA | Odds API `events` plus `participants` whitelist bind event and team IDs. | Exact `spreads` and `totals` two-sided snapshots, with bookmaker price and update time. | Odds API `scores` with event ID, completed status and score; adapter retains response/availability time. | Market settlement and certified close unavailable; any fitted model is research only. |
| NCAAB | Same Odds API event/participant binding; fuzzy school names are rejected. | Exact `spreads` and `totals` snapshots with price and update time. | Odds API `scores` is covered for NCAAB and retained with availability. | Provider IDs and complete captures are required; no certified close or bookmaker settlement. |
| MLB | MLB Stats schedule/feed provide `gamePk`, teams, start and score; Odds API has a separate event ID. Receipts retain both sides of a verified join. | Odds API run-line (`spreads`) and `totals` offers are captured in immutable pregame receipts. | MLB Stats final feed/outcome observations have recorded availability. | Any uncertain cross-provider join or missing independent-game/receipt lineage blocks canonical promotion. No certified close. |
| NHL | Odds API `events` plus `participants` whitelist bind event and team IDs. | Exact `spreads` represent the puck line; `totals` are separate. Bookmaker price and update time retained. | Odds API `scores` is covered for NHL and retained with availability. | Moneyline cannot substitute for puck line; goalie evidence is unavailable unless separately authenticated. No certified close/settlement. |

The [Odds API v4 reference](https://the-odds-api.com/liveapi/guides/v4/) documents events, participants, `spreads`, `totals`, prices, scores, and request/market update timestamps. Its [coverage table](https://the-odds-api.com/sports-odds-data/sports-apis.html) lists scores for all six leagues. [CFBD's game schema](https://apinext.collegefootballdata.com/api/games) includes game/team IDs, start, final scores and completion fields. The MLB Stats endpoint contracts used here are visible in `app_core/mlb_prospective.py` and `app_core/mlb_pregame_receipts.py`; their compatibility is verified by retained response replay, not assumed from a provider marketing page.

Across all six, a near-start snapshot is only a **close candidate**. `close_verified=false` and CLV is unavailable until an independently certified, replayable final-close source is implemented. A provider's generic score is not automatically a bookmaker settlement of a quoted line, including push/void rules. Missing identity, chronology, price, result availability or settlement provenance remains a blocker; no model, validation plan or dashboard row can turn it into wager authority.
