# Frozen prospective MLB totals diagnostics v1

Design: `mlb-total-inputs-v1`. Effective only for predictions generated by this version after deployment. No historical backfill. September 15 outcomes are not design inputs.

Unit: immutable snapshot ID + candidate ID, MLB total_over/total_under, recorded pregame. All candidate snapshots are retained; repeat predictions and opposite directions are correlated. This report does not estimate an independent betting record.

Signals counted: valid [0,1] TheOver, market, Kalshi, and model probability with exact matching ml_target. Signal count is presence, not independent corroboration. Missing TheOver, explicit stale empirical/recent-regime enum, missing target model, and explicit degraded-feature flag are recorded. No weather, pitcher, or lineup completeness is inferred.

INCOMPLETE: missing exact target model or fewer than two instrumented probabilities. DEGRADED: otherwise any instrumented reason. COMPLETE: otherwise. COMPLETE describes only these fields and is not validation or proof of complete context. Labels and sorted reason codes are saved before outcome collection and never recomputed by the report.

Metrics per status and separately Over/Under: sample, W/L/push/pending, W/(W+L), Brier and log loss for the saved calibrated_probability and decided outcomes only (log clip 1e-15), hypothetical one-unit ROI at original price including pushes. Missing probabilities/prices have separate denominators. CLV uses only hash-verified immutable closing observations recorded by activation_closing; latest capture per snapshot/candidate, line and same-line price CLV separately. No inferred closes.

All sample sizes are shown including small cells; no superiority claim or automatic test threshold. No automatic weights, gate, suppression, authority or promotion. Any policy proposal requires a separately frozen design and prospective evaluation accounting for game-level clustering. Retain v1 unchanged when defining later versions.
