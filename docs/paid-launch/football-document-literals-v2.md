The official Odds V4 guide publishes `apiKey=YOUR_API_KEY` and `apiKey={apiKey}`
as documentation examples. A labelled, network-blocked acquisition reproduction
on seal e23923f8 produced INCOMPLETE / DOCUMENT_CREDENTIAL_BODY with one spent
synthetic attempt. The original custody reader separately rejects these strings
with NFL_PRIVATE_CREDENTIAL_FORBIDDEN. No authentic request or secret was used.

`football-original-document-plan-v2` and its matching unreviewed-v2 bundle
recognize only those two exact noncredential literals, with token boundaries,
for document ID/source ID `clock`, exact URL
`https://the-odds-api.com/liveapi/guides/v4/`, HTML and no redirects. The temporary
scan view is not retained or substituted for the original. All other credential
patterns, suffix attacks, hosts, source identities and formats retain rejection.
V1 behavior is unchanged. Changed versions alter the plan hash and require new
exact permission/collection/configuration bindings; no old approval is reused.

Complete original bytes project into `nfl-public-guide-original-text-v1`, with
their unchanged hash, source identity and original clocks. Original custody and
V6/default callers reject that object. Only explicitly selected
`nfl-owner-public-document-private-inputs-v7` enables its reader while validating,
inferring or statically replaying the exact reviewed packet. Extraction,
interpretation and substantive owner findings remain distinct. V7 binds the
consumed original-text reader as well as the unchanged PDF/native predictor.
It creates no review, source acceptance, calibration, qualification or authority.

The versioned path preserves raw bodies, all request/byte/deadline/journal limits,
900-second freshness, pregame checks, exact offer/edition applicability and model
mathematics. No embedded example endpoint, link or resource is fetched. A
published placeholder is not a live credential, listing, price or permission.
Outputs remain OWNER_REVIEWED / PRIVATE_RESEARCH, uncalibrated, PASS and zero
stake, excluded from public packages. Existing rules/scoring/quote custody and
the saved Rams result are unchanged.

The original V1 proposal and all prior seals/receipts remain retained. The V2
four-document proposal has the same exact URLs, window and bounds but is a new,
unapproved, non-executable proposal. Body-size feasibility and exact listing
applicability remain authentic evidence requirements. Public-document research
does not establish original acquisition custody.
