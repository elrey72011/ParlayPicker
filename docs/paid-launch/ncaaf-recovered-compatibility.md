## Versioned contract

`app_core/ncaaf_model_compatibility.py` reads
`ncaaf-recovered-model-compatibility-v1`. The immutable software binding is
`docs/paid-launch/ncaaf-compatibility-binding-v1.json`.

`envelope(family="spread"|"total", model_name="ridge")` records the exact binding,
original/predecessor/artifact hashes, historical runtime declarations, the actual
current installed source hashes and Python/NumPy environment. Historical Python,
NumPy and dynamic alias contents remain UNKNOWN. Reviewed raw LF and CRLF byte
hashes are enumerated explicitly; historical runtime hashes are never normalized
or replaced. Changed component bytes or in-memory alias maps fail closed.
Unreviewed current dynamic alias files also fail closed.

`read_model(original_bytes, predecessor_bytes, envelope)` statically verifies the
exact byte IDs, recovery relationship, original chronology, complete artifact,
protocol, parameters and lineage, and returns the unchanged artifact with both
historical and consumed-reader identities. Another recovered model cannot borrow
the binding. `export_model`/`load_model` round-trip the complete original bytes.
No alternate binding can be supplied by an owner upload.

`app_core/ncaaf_compatible_observation.py` reads a separate
`ncaaf-compatible-prospective-inputs-v2` envelope. Required fields include the
private model export, exact event/schedule/crosswalk and accepted mapping receipt,
exact quote with clocks/period/rules evidence, seven ordered features with original
availability, dependency references and accepted offer-specific source review.
Dependency references must retain original season, game/team identities, source
hashes, availability and kickoff clocks. Three independent scoring and yardage
games per team must satisfy the strict seven-day boundary and current input-age
requirements. These are static receipts, not proof that feature arithmetic or
the underlying historical vintages were independently reviewed.

Capabilities are separately named selected-side full-game half-point cover and
full-game half-point over/under. Only the explicit ridge variant is supported by
this initial route. Other original variants are preserved but not enabled.
Integer push mass remains UNVALIDATED and UNAVAILABLE. Named orientation and
selected-side signed lines never become game-winner forecasts.

`read_observation` is static. It returns the verified fit and retained ordered
inputs, with `probability=None`; it does not compute or upgrade historical values.
Original inference clocks remain missing when missing. A later explicitly
authorized prospective caller integration must retain its genuinely new inference
clock, consumed runtime and actual dependency bytes. No historical packet is
automatically upgraded to v2 or re-keyed.

`ACCEPTED_EVENT_MAPPINGS` and `ACCEPTED_SOURCE_REVIEWS` are separate empty catalogs.
Compatibility never writes either, and never populates the existing normal
pipeline's accepted packet catalog. Source, calibration, scientific and wagering
flags remain false. Public display and actual wagering gates remain unchanged.
