# MLB research projection and NHL named orientation

This bounded successor preserves frozen version 10, the original baseline,
existing NFL/NHL implementations, all predecessor scope bindings, scientific
requirements and workflows. It neither registers sources nor changes any model,
calibrator, qualification, activation, staking or financial action.

## MLB before and after

An MLB producer can record successful target-specific score-model inference
while its exact offer lacks period and settlement evidence. Previously, a total
with this recorded producer contract could still qualify for the *unrecorded
legacy* public-metric compatibility branch: the protected research object was
unavailable, but public probability and binary EV aliases remained populated.
The corrected branch rejects that compatibility interpretation for recorded MLB
producer contracts. Private original raw probability, blend, EV and clocks stay
unchanged; public unavailable values stay unavailable together.

Novig MLB totals now receive an explicit negative source assessment, using only
the previously retained general rulebook document hash. That hash does not prove
a totals listing's applicability or settlement. Exact listing/product/provider
bridge, rule edition and effective clocks, full-game/extra-innings provisions,
void/postponement/shortening treatment and permitted uses require independent
evidence. Transport strings cannot supply those facts. No real source is added
to the accepted catalog, and no FVS payoff is represented as a binary refund.

The existing positive research path remains available when its exact producer,
selected offer, target, source and period/settlement contracts pass. Synthetic
tests exercise a separately declared non-Novig contract with explicit research
fallback. They establish software behavior only. Existing Novig FVS suppression
of binary EV/edge/break-even remains in force.

The private replay projection additionally retains the five existing allowlisted
`mlb-total-inputs-v1` diagnostics. It copies original states rather than deriving
or repairing them during replay. Older packets that lack these fields are not
backfilled. Synthetic pipeline/capture/export/rebuild now preserves these exact
fields and public/private separation.

MLB home Run Line qualification remains its own existing scope. Neither an away
Run Line nor a total inherits its validation, calibration or wagering authority.

## NHL before and after

The mapper previously collapsed both New York NHL franchises into `New York`.
Full Rangers/Islanders names and their explicit `NY` aliases now retain distinct
canonical names through repeated normalization, without changing provider event
IDs or reversing named home/away orientation. A bare `New York` remains ambiguous.
Existing historical packet names and IDs are not rewritten or upgraded.

The merged explicit offline path remains
`nhl-selected-full-game-half-point-cover-v1`: selected-side full-game ±1.5 cover,
including the required overtime/shootout settlement semantics. Connecting it to
normal-pipeline inference requires an explicitly selected existing local research
store, an original canonical event and exact quote, original available-at clocks,
retained provider-final-score team histories, an exact compatible cover-model
artifact and its training/out-of-sample lineage, and accepted source/target/rights
reviews. The existing context manager already routes that selection through the
actual market-probability caller. No authentic qualifying artifact or history is
manufactured by this change, and default inference is not enabled.

Unavailable features, histories, exact source terms or model artifacts retain
their existing precise adapter reasons. Standings, a game-winner classifier,
market-implied probability or a synthetic fixture cannot substitute for that
cover model. Goalie inputs remain explicitly UNKNOWN under the existing contract.
NHL totals require a separate target, feature and settlement design.

## Verification

New synthetic tests use actual odds extraction, target-specific inference,
candidate capture, private replay export/rebuild and public browser rendering
with network transports blocked. They test both missing and asserted-but-unverified
Novig terms, a complete identity-bound research contract, unchanged original
numbers/clocks, zero stakes, private-data exclusion, and named NHL orientation.
Predecessor tests remain unchanged. Exact implementation and a subsequent
policy-only seal bind this successor to verified merged main; CI supplies no
scientific qualification or wagering authority.
