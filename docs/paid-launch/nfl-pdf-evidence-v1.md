# Original PDF evidence for NFL private research

The merged v4 reader rejects binary PDFs as NFL_PRIVATE_CUSTODY_CLOCK_UNKNOWN;
changing their receipt format to text rejects as NFL_PRIVATE_RESPONSE_SCHEMA.
Novig's complete NFL Spread contract is published as PDF. Its HTML policy page
establishes the governing framework but does not replace that contract.

Explicit nfl-owner-pdf-private-inputs-v5 dispatch uses the existing private caller,
capture/export, static replay and display mechanisms. v1/v2/v3/v4 input readers,
custody, interpretation, historical packets and rejections remain unchanged. A
new PDF packet cannot borrow their review. Original response bytes and receipts
are distinct from extraction, interpretation, owner verification and inference.

## Custody and extraction

nfl-original-pdf-custody-v1 retains complete original PDF bytes, their SHA-256 and
the actual source/HTTPS receipt. Original request, receipt and observation clocks
are required; missing clocks stay unavailable. A file modification, filing or
retrieval date is not substituted for any missing clock or effective interval.

nfl-pdf-page-extraction-v1 binds the exact PDF to pypdf 6.20.0, its aggregate Python
package-source hash, this adapter's source hash, actual Python version, extraction
preparation clock and complete page list. Both plain and layout text are retained
with hashes. Their non-whitespace glyph multisets must agree, and each supporting
page/character locator and surrounding context must agree unambiguously in both
views. Output is a derived projection, never an original text response. No OCR,
partial extraction or repairs are labelled complete. Single-revision PDFs only;
incremental/multiple-EOF bodies remain unsupported rather than guessed complete.

An isolated -I -B decoder process cannot reexecute the application or caller main.
It denies networking, never follows links and rejects active/embedded content,
encrypted PDFs, invisible/rotated text, unsupported filters, unreadable pages,
missing EOF, inconsistent extraction and ambiguous supporting locations. Parser
exceptions become bounded codes; raw messages and traceback locals are omitted.
Inert URI references remain untrusted and cause no retrieval.
Credential checks cover original bytes, decoded streams, metadata keys/values and
credential-bearing URI references, as well as visible page text. A rejected source
is not redacted and relabelled complete.

Original bounds remain 512 KiB per non-scoring body, 6 MiB total original evidence,
12 MiB serialized packet and 16 MiB combined selected packets. No HTTP limit,
attempt, source endpoint, deadline or approval changed. New internal extraction
budgets are 32 pages, 128 KiB combined plain/layout UTF-8 text, 16 KiB per page,
512 KiB per decoded stream, 4 MiB total parser streams, 4,096 references, depth 32
and eight seconds per isolated decoder. The 4 MiB parser-stream budget accommodates
retained embedded font streams; it does not enlarge a response/body/packet budget.
Oversize sources/projections reject; no truncation or source splitting.

Only pure exact-content extraction is cached (two entries, raw bytes, method and
parser identities). Current parser bytes are checked before cache use. Clocks,
interpretations, permissions, reviews and admission are checked afresh.

## Interpretation and admission

nfl-pdf-source-interpretation-v3 records exact page/span/extraction hashes and
substantive Robert findings/reasoning/time against the exact subject. Extraction
preparation precedes interpretation preparation and owner verification; required
verification precedes genuinely new inference. Unknown publication remains
UNKNOWN. Processing or a button creates no review or acceptance catalog entry.

The same v4 gate also rejects the previously reviewed original-receipt namespace
proof. The successor reuses that exact source_projection proof solely for its
provider_namespace field, labelled OWNER_INTERPRETED receipt attribution rather
than an emitted provider column. Verified JSON integers/booleans preserve their
original types; they are not invented from absent source fields. All other source
proofs, event identities, applicability and review findings remain mandatory.

The existing bounded NFL meanings and full-game/OT half-point scope are unchanged.
Exact event/offer/reference-team/threshold/YES-NO mapping, applicable edition,
amendments/effective intervals, listing-specific overrides and FVS restrictions
remain required. Generic contracts establish no particular listing. Filenames or
filing/retrieval dates establish no effectiveness. Unsupported conclusions reject.
Quote freshness stays 900 seconds from the original provider market observation;
receipt, extraction or review cannot renew it. Pregame, source permission, scoring
custody, feature order/history, native mathematics and model binding stay intact.

Results are uncalibrated OWNER_REVIEWED / PRIVATE_RESEARCH, PASS at zero stake,
excluded from public packages, source acceptance, calibration and qualification.
The saved Rams scenario and its clocks/result are unchanged and not rerun.

## Authentic readiness

Retained public-research originals exist: the 403,625-byte Novig contract and
293,631-byte Ludlow filing. Static extraction verifies their exact hashes and all
20/12 pages. Their older byte receipt records retrieval time but not request-start
and separate receipt clocks; formal custody is not complete. No clock is invented.
The 159,952-byte class filing has multiple EOF revisions and stays unsupported.
PDF support does not decide exact listing applicability, edition or effective dates.
Parsed website references are not original response custody.

Before a result quote: stage complete schedule/clock/contract documentary custody,
review source permissions and applicable terms, then resolve an exact observed
listing reference using a separately authorized identifier capture if necessary.
Returned links require their own bounded retrieval review. Finish documentary
verification before a separately authorized fresh result quote when the first
quote would expire during review. Every capture stops CAPTURED_UNREVIEWED; later
exact-subject owner review and explicit prospective-inference authorization remain
separate. There is no automatic retry, inference or trust activation.
