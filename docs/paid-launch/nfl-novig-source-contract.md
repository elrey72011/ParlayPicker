## Provider facts and bookmaker facts

[The Odds API markets](https://the-odds-api.com/sports-odds-data/betting-markets.html) defines `spreads` as a bookmaker's handicap market and separately names half/quarter markets. It supplies no explicit blanket overtime, cancellation or settlement guarantee. [V4 documentation](https://the-odds-api.com/liveapi/guides/v4/index.html) describes event/team/start identities and market-level `last_update`; bookmaker-level update is deprecated. The exact matched market clock takes precedence, with the existing bookmaker fallback preserved. [The bookmaker list](https://the-odds-api.com/sports-odds-data/bookmaker-apis.html) lists `novig` in `us_ex`; that alone does not prove a specific quote's legal product/listing or rule edition.

The [official Novig contracts index](https://support.novig.com/en/articles/16083642-contracts) links the NFL Spread Series template, ticker NFLSPR, rule code NFL-001, public appendix PDF pages 4–11. It defaults to the whole game including overtime unless the listing specifies another period; half/quarter/regulation variants are also possible. Settlement measures the named reference team's margin against a strict threshold. Half-integer thresholds cannot equal an integer final margin. Unequivocally determined results settle even without an official completion designation; otherwise abandonment/shortening can void. Scheduling uses the designated week, formal rescheduling/24-hour commencement exceptions, 48-hour suspension resumption, and a separate 45-day postseason rule. Format changes, unresolved results, ambiguous makeup identity and other specified contingencies can void.

Voids use the template's fair-value settlement, with a 30-minute pre-reference window and ordered fallbacks; funds return only if fair value cannot be determined. The [official FVS explanation](https://support.novig.com/en/articles/16163706-what-is-fair-value-settlement-fvs) corroborates this distinction. Do not replace the NFL-specific scheduling provisions with the generic support article's “most markets” reschedule rule. Half-point no-push does not imply no void or stake-refund settlement.

The index publication date is September 2, 2026; NFL PDF HTTP Last-Modified is July 29, 2026. Neither establishes legal effective applicability to the October 4 retained offers. The PDF's contract variables are unpopulated. Exact listing terms, reference/YES mapping, product identity, provider-to-listing bridge, effective window and contemporaneous verification remain UNKNOWN. A predictor's full-game target cannot establish any of them. No historical field is backfilled from this retrieval.

The [governing Rulebook](https://support.novig.com/en/articles/16075446-ludlow-exchange-llc-rulebook), Version 1.3 (metadata title August 27; index September 2), is separately hash-pinned. Rules 7.1–7.2 permit outcome review and announced changes to underlying/specifications/expiration. Effective listing notices and overrides therefore require original applicability evidence; the receipt must remain effective through original inference, not merely at the older quote clock. Rule 12.1 restricts members' reuse of proprietary information including market data; exact direct-listing/data rights remain a separate owner-specific dependency.

[The Odds API terms](https://the-odds-api.com/terms-and-conditions.html), last updated August 31, expressly permit storage, research, model training, derived values and UI use while restricting standalone raw-data redistribution. These public terms are evidence of the provider's general usage policy, not proof of the owner's applicable subscription, direct Novig-data rights or permission to execute scientific fitting in this task. A provider license cannot silently establish a separate operator listing/data grant.
