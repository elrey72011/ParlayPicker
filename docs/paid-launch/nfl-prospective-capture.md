## Recorded facts and limitations

The feature order follows the fixed score reader: home/away PPG, home/away opponent PPG, home/away games played, home/away win percentage, recent-form difference, home/away recent point margin. Exact names and input states are retained. Missing optional values remain missing; their transformations are defined by the pinned original code. Required scoring/games inputs must exist. The observation receipt is reused, not promoted to verified source availability.

`nfl_feature_dependencies`, when actually supplied by the feature boundary, maps each present feature to a payload/hash receipt with feature/value, source ID, provider event ID, available_at and observed_at, hash-verified original source bytes and exact value/event paths. Dependencies must match values/event and satisfy availability ≤ observation ≤ original inference < kickoff. No current adapter is claimed to provide these upstream facts: absent receipts remain UNKNOWN. Hash agreement demonstrates retained integrity, not independent verification or source rights.

The raw score probability is distinct from the market/context research blend. The legacy calibrated_probability column is recorded as a research blend, not a fitted scoped calibrator. The estimated EV is recorded as a binary price estimate, not certified operator payoff. Existing Novig FVS value suppression remains intact. No other bookmaker receives these probabilities or EV by copying an alternative quote.

COMPLETE means all required supplied packet bindings pass the software validator; it does not mean scientific acceptance, licensed use, applicable operator settlement or production eligibility. INCOMPLETE identifies absent upstream facts without denying a valid existing research display. REJECTED identifies malformed/missing consumed inputs, corruption, contradictory identity/output, or invalid clocks and suppresses display. Explicit missing operator period/rules continue to reject through existing source/display checks.

Offline replay verifies installed exact predictor/weights/configuration/runtime and pipeline identities, recomputes raw and blended probabilities from retained inputs, and checks equality. It never executes saved code, loads a fitted classifier, fits a calibrator, acquires data, registers receipts or replaces predictions. Mismatched environments/artifacts fail closed. Retention failures produce explicit rejection without aborting the computed model/blend. Existing snapshot/export hashes and owner download integrity still protect the entire source; packet self-hashes alone are not authenticity signatures.
