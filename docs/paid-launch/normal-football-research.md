# Explicit normal football research inputs

This successor adds a normal-caller NCAAF research path over the private #2396
target contract. NFL retains its existing selected-side spread caller, native
provenance, private export and separately validated UI refresh. No calibrator is
fitted or source registered. Research output remains PASS with zero stake.

## NCAAF software path

After the existing owner publishing-token gate, Publish board → Private NCAAF
research inputs stages an existing private target JSON packet in session memory.
Selection changes the next analysis signature; it does not increment the analysis
run counter or run analysis. No store is opened and no provider is called by the
panel. At most four packets, 8 MiB each and 16 MiB selected total are allowed.
The panel rejects synthetic uploads. Tests inject explicitly synthetic packets.

The normal caller invokes the native adapter only when explicitly selected, even
if the unrelated home-win feature gate is unavailable. It requires one unchanged
exact event/offer/selected side/signed line/price/clock/book and a unique original
quote. Provider IDs come from that receipt; conflicting aliases stay rejected.
Spreads use the native home-margin distribution with selected-side sign; totals
use the distinct total-score distribution. Home-win probabilities are retired.

The original private contract still requires the exact frozen native runtime and
artifact, ordered seven features, explicit neutral site, at least three prior
scoring and yardage games per team, original dependencies available before the
capture, and strictly more than seven days between prior games and target.
Evaluated 2025 outcomes cannot become untouched. Future out-of-sample events must
be after the artifact's evaluation window. This change does not alter the native
model, its reader, historical protocol, lag, minimums or integer distribution.

Initial display accepts only half-point spreads/totals. Integer push mass remains
explicitly unvalidated. A fresh inference requires the unchanged quote within
15 minutes, original capture finish before inference, dependencies within their
existing 24-hour limit, and inference before kickoff. Stale historical packets
are rejected before numerical feature or model reading. The native v1 missing
per-model inference clock remains null; a new inference records its own time.
Capture finish cannot substitute for an old missing inference clock.

An independently accepted exact packet/source-review hash and separately accepted
public derived-output permission are mandatory. `ACCEPTED_PACKETS` is empty.
Upload/selection cannot write it. Original full-game period, settlement, product,
operator, listing, effective terms and source rights must already be bound by the
private contract. Novig's FVS payoff is not admitted through its binary route.
Missing original facts cannot be filled with another bookmaker's terms.

## Retention and display

Private `ml_estimate_metadata.ncaaf_inputs` retains the unchanged original packet,
native feature/dependency/model records, artifact/runtime, consumed reader hashes,
raw native probability, new inference clock and separate original normal-pipeline
blend. It records no UI-refresh output. The legacy `calibrated_probability` name
does not prove calibration. Public research display selects `ml_probability` only
for this validated NCAAF contract; it does not claim that raw-model acceptance
validates the original blend. It exposes no settlement value or private packet.

The independently matched ESPN board event remains distinct from the Odds API
offer ID and CFBD feature event. A scoped producer schedule binding preserves the
original ESPN key/status, selected source event, observation clock and original
inventory hash through authority projection, capture and replay exports. The
retained schedule receipt is scoped to that event; it does not claim that the
whole inventory was exported. Missing opposite prices remain explicit and confer no
value estimate. Existing guards for all other producer contracts remain intact.
The normal board still requires its existing corroborated signed-price pair when
favorite orientation is absent; probability integration does not bypass it.

FBS and FCS inventory remains independent of quote availability and the frozen
Stage 1 FBS-only cohort. This adds no default FCS model or new capture cohort.

## Acceptance and next evidence

Network-blocked synthetic tests exercise the actual native capture, all four
half-point selections, normal caller, canonical private capture, retained replay
export, supported-book per-game fallback and browser. Negative checks cover stale
and future clocks, changed offers, duplicate packets, corruption, unsupported
push/source/rights, altered features, failed inference, owner authorization,
schedule/side conflicts and public/private separation. Synthetic success does not
establish authentic acceptance, scientific qualification or wagering authority.

For NCAAF, the next authentic prerequisite is an existing nonempty native capture
with a compatible consumed model/runtime and exact source/period/rules/rights
review. Old artifacts or empty captures are preserved, not silently migrated.
An existing incompatible runtime needs an independently reviewed compatibility
decision before reuse; this successor grants no such exception.

For NFL, inspect a complete original selected-side half-point spread packet first.
Retain raw model, original blend and UI-refresh output separately. The existing
normal research path can display only an identity-bound source-compatible estimate;
unverified listing/period/rules/rights remain precise blockers. Novig FVS terms
continue to prohibit treating the probability as ordinary binary EV. Settlements,
calibration fitting, chronological validation/untouched custody, qualification and
current wager authority remain separate work requiring their existing reviews.
