# Private exact-offer source-evidence intake

This bounded software change extends the existing source-contract adapter and append-only research replay database. It does not register a source or listing. The real `ACCEPTED_LISTINGS` catalog remains empty. Only synthetic tests supply independent accepted review bindings.

After the existing owner-token check, the private publication panel can retain an existing JSON packet and download its original bytes. Select retained packets for the next explicitly requested analysis. Selection is local to that run; saved predictions and separately retained UI-refresh stages are not rewritten. Configure the existing evidence directory outside the repository before using intake. No URL is fetched and no document is executed.

The `exact-offer-source-evidence-v1` packet contains `evidence` and a separate `review`. Evidence includes the original document bytes as base64, their SHA-256 hashes, source references and provision locators; exact provider/event/offer facts; legal operator/product/jurisdiction; provider-to-listing bridge; named orientation and signed handicap; original American price and source clock; full-game/overtime terms; rule edition and effective window; scheduling/cancellation/void/FVS terms; original-clock meaning; and owner-specific storage/research/derived-output rights and limitations. Each applicability purpose must reference a supplied document. Document content, generic market names and uploader assertions do not prove applicability.

The source packet's inference clock is optional because source documents cannot predict a future model invocation. The existing producer records the actual original inference clock independently. Replay requires it to fall after the original quote, before kickoff, and inside the rule, rights and accepted-review windows. Any separately supplied original inference clock must match exactly. Market-level `last_update` retains precedence, with bookmaker fallback; intake binds the actual field used.

The separate `exact-offer-source-admissibility-v1` review records reviewer, review identity, decision, evidence/identity/product/rights hashes, rule version and review window. Uploading an ACCEPTED decision does not accept it. An independently trusted existing catalog entry must bind both the complete packet hash and review hash. This task adds no registration or approval action. Reviewers must inspect the original documents and exact offer bridge; software cannot establish their legal applicability from bytes alone.

NFL / Odds API / Novig half-point spreads reuse the existing FVS source adapter and value guard. This does not accept a real Novig listing or legal product, establish DraftKings jurisdiction/product, cover NFL totals or MLB spreads, or broaden an accepted source. Missing required facts produce UNKNOWN; conflicting identities, invalid clocks, unsupported scopes, altered documents and contradictory acceptance bindings reject. A rehashed packet without an independent matching review is unaccepted. Public displays show precise source-evidence reasons and suppress rejected legacy estimates.

Original document bytes, review details and private intake metadata travel in the existing private producer/snapshot/export/replay carrier. Public packages exclude them. The legacy-reader projection recognizes a retained UI-refresh receipt only after COMPLETE validation; it leaves both original stages untouched in storage. Synthetic acceptance tests verify unchanged raw and blended probabilities and original clocks through native adapters, the actual analysis pipeline, capture, export, private replay and browser.

A complete synthetic accepted contract can display a decided-game research probability. Novig EV, edge and break-even remain unavailable without FVS-compatible contingent payoff evidence and an accepted value reader. Research remains PASS with zero stake and supplies neither scientific qualification nor wagering authority. Prediction formulas, weights, calibration, eligibility gates, frozen calendars and operational/financial behavior are unchanged.

Before production use, obtain exact provider-to-operator/listing and YES/NO/reference/count/price-unit evidence, the applicable rule edition/window and contingencies, original clock meaning, owner-specific rights and independent source-admissibility/reader review. The existing inquiry remains private and unsent. Collection requires separate authorization and an approved research protocol; this implementation does not authorize it.
