# NHL selected-side full-game half-point research path

This is an offline software path, with no accepted real source review or default
research store. It acquires nothing, fits no real data, changes no source catalog,
and grants no scientific acceptance or wagering authority. All unqualified NHL
selections remain PASS with zero stake. Frozen version 10, calendars, scientific
floors, workflows and predecessor policies remain in force.

Previously the market-probability producer had no NHL spread/total model adapter.
The new adapter reads an explicitly selected local canonical evidence database,
uses the existing prospective NHL PUCK_LINE score-form artifact and feature reader,
and retains its actual inputs at the market-probability boundary. The target
`nhl-selected-full-game-half-point-cover-v1` is the probability that selected-side
official final score margin plus that side's signed handicap is greater than zero.
Only home/away ±1.5, full game with independently reviewed overtime and shootout
semantics, is supported. Away uses the negative of the named home-margin forecast
and its own signed line. Neither a game-winner probability nor market-implied
probability supplies the independent forecast; the existing later market/context
blend is separately retained and is not genuine scoped calibration.
The market producer calls this adapter only inside the explicit offline selection
context. Default callers retain their governing unavailable behavior, and leaving
the context does not activate subsequent calls.

Native event/quote identities, original bytes and receipt hashes, prices, operator/
product review, periods/rules, quote/inference clocks, ordered seven score-form
features, authentic prior score/event dependencies and their availability, model
receipt/artifact and installed runtime/code identities are retained privately.
The supplied source review binds exact event/quote/artifact/dependency hashes and
the versioned target. It is separate from feed flags. Its assertions require
independent admissibility review before real use; hash consistency does not prove
source authenticity. No accepted real review is shipped or registered.

Home and away goalie inputs are explicitly UNKNOWN with
NO_AUTHENTIC_GOALIE_STATUS_FEATURE. The reused score-form feature version consumes
no goalie data. Adding goalie, injury, roster or other inputs requires authentic
point-in-time receipts, a new ordered feature contract and scientific review; it
cannot be silently imputed or called available. Existing synthetic fitting tests
train only on generated provider-shaped games to exercise the software path.

Actual pipeline blending, capture, immutable private export and replay retain raw
cover probability and original blend separately. Replay uses installed code and
consumed artifacts, never executes retained code, and checks exact named orientation,
quote, target, feature reconstruction, prior availability, artifact hashes and blend
configuration/output. Later unsupported refreshes cannot silently reuse the original
blend receipt. Precise failures remain unavailable. The research display validates
the packet before accepting it, suppresses settlement EV/edge/break-even, and exports
no features, model coefficients, private reviews or dependency receipts.

Real gaps remain: an admissible operator/product/rule/right/clock review, canonical
original event/offer and pre-inference authentic team histories, an independently
reviewed existing artifact with demonstrated training/out-of-sample lineage, and
exact-offer settlements. No real selection or launch date follows from fixtures.

Totals require a separate versioned total-goals target, over/under and exact line
orientation, explicit full-game or regulation score/rule semantics, push/void/payoff
semantics, an independently scoped TOTAL artifact and feature contract, original
data/source reviews, and calibration/evaluation support. A puck-line or winner
artifact cannot substitute for a totals model. This draft leaves NHL totals
unavailable with a separate-target reason when an offline store is selected.
